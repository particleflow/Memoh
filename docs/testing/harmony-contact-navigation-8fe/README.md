## Product scope

The shared sidebar contacts are primary; existing history/debug, folders, sessions and settings remain secondary. An existing bound contact is reused. One server-verified ordinary old chat binds its original ID directly without a new permission prompt. Only multiple genuine candidates require selection, and Cancel performs no bind. Empty history uses the existing native atomic resolver. Explicit `/bot/<name-or-id>?session=<uuid>` navigation stays on that original session rather than changing the durable contact.

The existing builder adds only the hash-guarded source fragments, exact generated contact SDK declarations and two shared locale blocks. It consumes `GET /bots/{bot_id}/sessions/contact`, bodyless `POST` on that route, and `POST /bots/{bot_id}/sessions/contact/bind` with `{session_id}`. UUID/account/eligibility/ownership rules remain server-owned. Contact ID and temporary history selection remain separate. Existing queued tasks, unknown operations and saved history are neither moved nor resubmitted.

The superseded global activity sidebar overlay is removed so it cannot overwrite the shared contact panel. The existing drawer's lazy file/schedule mounting remains. The conversation-scoped Agent/sub-Agent/Bot relation trigger stays active. Status display maps only native `errored`/`admitting` via the original shared helper; raw state, name and clicked object are unchanged. No management expansion, new permission, protocol, provider or dependency.
